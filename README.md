## Principles

1. **Primary sources only.** No commentary, no interpretation, no intermediation. The texts speak for themselves.
2. **Decentralized.** Content-addressed storage. No central server to seize. Forkable. Mirrorable.
3. **Free.** Public domain or openly licensed. No paywalls. No gatekeeping.
4. **Complete.** Full texts, not excerpts. Multiple translations where available.
5. **Attributable.** Every text has a SHA256 hash for integrity verification.

## File Format

All texts are plain `.txt` files, UTF-8 encoded. The catalog (`catalog.json`) contains full metadata: title, tradition, category, word count, file hash, and preview.

## Catalog

See `catalog.json` for the full machine-readable index. Each entry includes:
- `id`: unique identifier
- `title`: display title
- `tradition`: tradition classification
- `category`: directory/category
- `size_bytes` / `size_human`: file size
- `word_count`: total words
- `sha256`: integrity hash
- `preview`: first 200 characters
